# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for OUI.

ADRs capture significant technical decisions together with their context, rationale, alternatives, and consequences. Once accepted, an ADR is not rewritten to hide a superseded decision. A later ADR should supersede it and link back to the original record.

## Statuses

- **Proposed** — under discussion and not yet binding.
- **Accepted** — the current architectural decision.
- **Deprecated** — retained for compatibility but no longer preferred.
- **Superseded** — replaced by a later ADR.
- **Rejected** — considered and explicitly declined.
