# `@oui/react-aria`

The default accessible implementation of OUI's headless primitive contract.
Its exported props are owned by OUI and do not expose React Aria types.

The package provides button, link, field, selection, dialog, popover, feedback,
status, stack, and inline primitives. Import `@oui/react-aria/styles.css` only
when you want the optional semantic-token-based presentation.
